# 🔐 Password Manager

A Python-based credential vault allowing users to store, retrieve, update, and delete service credentials with administrative password authentication.

![Python Version](https://img.shields.io/badge/python-3.x-blue.svg)
![Security](https://img.shields.io/badge/security-Admin%20Protected-red.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

---

## 🔑 Features

* ➕ **Store Credentials**: Save service names, usernames, and passwords with duplicate prevention.
* 🔍 **Retrieve Passwords**: Search saved accounts via admin authorization[cite: 3].
* ✏️ **Edit Records**: Selectively update usernames or passwords[cite: 3].
* 🗑️ **Delete Credentials**: Permanently remove obsolete entries[cite: 3].
* 🛡️ **Admin Protection**: Key management operations require master admin passcode verification (`getpass` masked input)[cite: 3].
