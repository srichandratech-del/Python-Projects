## Overview

Basic Calculator is a simple command-line Python project that performs fundamental arithmetic operations. It was created as part of my Python learning journey to practice variables, user input, functions, conditions, and basic error handling.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- User input through the command line
- Basic input validation
- Division-by-zero protection

## Concepts Practiced

- Variables and data types
- User input with `input()`
- Conditional statements
- Functions
- Arithmetic operators
- Error handling
- Basic program structure

## Requirements

![Python](https://img.shields.io/badge/Python-3.x-3776AB?style=flat-square&logo=python&logoColor=white)

Python 3.x is required to run this project.

## Running the Project

Clone the repository:

```bash
git clone https://github.com/srichandratech-del/Python-Projects.git
```

Navigate to the project folder:

```bash
cd "Python-Projects/Basic Calculator"
```

Run the program:

```bash
python Basic_Calculator.py
```

## Example

```text
------------------------------
| Welcome To Basic Calculator |
------------------------------

Enter First Number: 12
Enter Second Number: 14
Enter operation (add/sub/mul/div): Addition
------------------------------
Answer =  26.0
------------------------------
```
