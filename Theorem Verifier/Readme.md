## 🧾 Overview

**Theorem Verifier** is a command-line Python tool that **verifies mathematical theorems** and **calculates widely-used mathematical formulas** — all from a simple interactive menu.

Built as part of my **Python learning journey**, this project reinforced core programming concepts such as functions, user input handling, conditional logic, and Python's built-in `math` module through real, practical mathematical implementations.

---

## ✨ Features

| # | Feature | Description |
|---|---------|-------------|
| 1 | **Pythagoras Theorem** | Checks if `c² = a² + b²` holds for given side values |
| 2 | **Triangle Angle Sum** | Verifies if three angles sum to 180° |
| 3 | **Exterior Angle Theorem** | Confirms exterior angle equals the sum of the two non-adjacent interior angles |
| 4 | **Distance Formula** | Calculates the distance between two coordinate points |
| 5 | **Midpoint Formula** | Finds the midpoint between two coordinate points |
| 6 | **Slope Formula** | Computes the slope of a line between two points |
| 7 | **Quadratic Formula** | Solves quadratic equations and finds real roots |
| 8 | **Heron's Formula** | Calculates the area of a triangle from its three sides |
| 9 | **Vector Magnitude** | Computes the magnitude of a 3D vector |
| 10 | **Binomial Theorem** | Expands and evaluates `(a + b)ⁿ` |
