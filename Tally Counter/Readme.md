# 🔢 Tally Counter

A terminal-based tally counter utility designed to keep track of incremental or decremental counts via an interactive loop menu.

![Python Version](https://img.shields.io/badge/python-3.x-blue.svg)
![Status](https://img.shields.io/badge/status-active-brightgreen.svg)

---

## ⚙️ Features

* ➕ **Increment**: Increase tally count by 1[cite: 5].
* ➖ **Decrement**: Decrease tally count by 1[cite: 5].
* 🔄 **Reset**: Reset tally back to zero[cite: 5].
* 🛑 **Exit**: Safely terminate program session[cite: 5].

---
